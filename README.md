## **Chat en tiempo real**

# **Descripción**
Este proyecto consiste en una aplicación de chat en tiempo real, inspirada en  WhatsApp. La idea es poder comunicarse con otros usuarios mediante chats, permitiendo enviar y recibir mensajes de forma instantánea.
La aplicación permite registrarse e iniciar sesión, consultar las conversaciones existentes, crear nuevos chats, ver el historial de mensajes y comunicarse con otros usuarios en tiempo real.
